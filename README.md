## 💼 Mon stage chez OET Automation

**Développeur full-stack stagiaire · OET Automation / Ovalt**  
11 mai — 11 août 2026

J'ai participé à l'évolution d'une application interne de suivi de la performance des affaires. Mon principal travail a été de concevoir et développer un module de tickets pour suivre les **actions, évolutions et risques**, avec des informations propres à chaque équipe.

- Conception des modèles de données avec Django et PostgreSQL.
- Développement de l'API REST avec Django REST Framework.
- Création de tableaux filtrables, de formulaires dynamiques et d'un historique dans l'interface Vue.js.
- Mise en place de notifications par email et du suivi des modifications.
- Configuration du débogage Django dans Docker avec debugpy et VS Code.

Les fonctionnalités développées sont utilisées par les équipes de l'entreprise. Ce stage m'a appris à intervenir dans une base de code existante et à suivre une fonctionnalité du modèle de données jusqu'à l'interface.

*Cette section présente mon expérience, sans publier le code ni les données de l'application interne.*
